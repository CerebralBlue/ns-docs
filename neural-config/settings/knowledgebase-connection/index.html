KnowledgeBase Connection

KnowledgeBase Connection decides where NeuralSeek looks when it answers a question: which store it searches on every Seek, how it signs in to that store, and which fields of the returned documents hold the passage text, the link and the title. Every other retrieval setting acts on what this connection returns, so a wrong type, a bad credential or a mismatched field mapping shows up later as empty answers, untitled sources or broken links.

The section changes shape with KnowledgeBase Type. Three controls are always there; everything below them belongs to the type you pick.

Where to find it

Section titled “Where to find it”

Go to Neural Config, select the Default Config node (Answer Generation) in the routing tree, and open its Edit Configuration dialog. In Configuration: Default Config, expand KnowledgeBase Connection, the first section. The other sections of the dialog are listed in the Neural Config directory.

To keep your changes, select Save at the bottom of the dialog, or Propose Changes to keep them for review; Save or propose a change explains both. A category with its own custom configuration has the same section, see Give a category its own settings.

NeuralSeek KB, No KnowledgeBase and Virtual KB

Section titled “NeuralSeek KB, No KnowledgeBase and Virtual KB”

These three types need no endpoint, credentials or field mapping.

  • NeuralSeek KB is the NeuralSeek-hosted knowledge base. The section keeps only KnowledgeBase Type, KnowledgeBase Language and Notes, because the store is part of NeuralSeek.
  • No KnowledgeBase also keeps only those three controls. Choose it for a configuration that should not search any store. With this type, KnowledgeBase Tuning shows Snippet size in place of Expansion Window.

  • Virtual KB adds one dropdown below Notes, mAIstro Virtual KB agent: the mAIstro agent that acts as the knowledge base. What that agent receives and must return is covered in Virtual KB.

Watson Discovery and Watson Discovery (CP4D)

Section titled “Watson Discovery and Watson Discovery (CP4D)”

Both Discovery types point at a Discovery project. They differ in how NeuralSeek signs in: an API key on IBM Cloud, a user name and password on Cloud Pak for Data.

SettingTypeWhat to enter
Discovery Service UrlBothThe Discovery instance URL. On IBM Cloud it has the form https://api.us-south.discovery.watson.cloud.ibm.com/instances/<instance id>; on CP4D it is your cluster’s Discovery API address.
Discovery API KeyWatson DiscoveryThe API key of the Discovery instance.
Discovery User NameWatson Discovery (CP4D)The Cloud Pak for Data user NeuralSeek signs in as.
Discovery PasswordWatson Discovery (CP4D)That user’s password.
Discovery Auth URLWatson Discovery (CP4D)The Cloud Pak for Data authentication endpoint of your cluster, which ends in /icp4d-api.
Discovery Project IDBothThe Discovery project to search.

The password fields (Discovery API Key, Discovery Password, AppSearch Private API Key, ElasticSearch Private API Key, watsonx Discovery Private API Key, OpenSearch Password and Postgres Password) each have a Show password button inside them that reveals what you typed, so you can check it before you save.

Both types continue with the full field mapping block, including the additional payload fields and Return the full document instead of passages.

Field mapping

Section titled “Field mapping”

Every external store, that is every type except NeuralSeek KB, No KnowledgeBase and Virtual KB, follows its connection fields with a mapping block. It tells NeuralSeek which field of your documents is the passage text, which is the link and which is the title. NeuralSeek builds each answer’s source title and link from these fields, so a wrong mapping gives answers with untitled sources or no links.

SettingWhat it does
Curation Data FieldThe field that holds the passage text, the content NeuralSeek takes passages from.
Link FieldThe field that holds the document’s URL, shown as the source’s link.
Document Name FieldThe field that holds the document’s title, shown as the source’s name.
Additional Payload FieldOne more field of your documents to bring back with each result.
Include additional Payload Field inside LLM contextWhether that extra field is also put into the text the LLM answers from, not only returned with the result. Use it when the field carries facts the answer needs.
Attribute sources inside LLM Context by Document NameOffers Enabled and Disabled. Enabled introduces each passage to the LLM with its document name; Disabled passes the passages without names.
Return the full document instead of passages (only enable this if all of your documents are short)Sends each matching document whole instead of the passages taken from it. Turn it on only when every document in the store is short; leave it on Disabled for long documents so that NeuralSeek works from passages.

With Attribute sources inside LLM Context by Document Name set to Enabled, each passage reaches the LLM as “The document ’…’ states that: …”.

The mapping lists offer the fields of your store, and the values a list shows after you pick a type (such as title or url) only work if your index uses those names.

While the connection fields are empty, an open mapping list shows only its current value and Loading data.... Fill in the connection fields above it first, then pick the field.

Filtering, re-sorting and Enable Advanced Schema

Section titled “Filtering, re-sorting and Enable Advanced Schema”

The end of every external store’s form restricts which documents a Seek can return and pushes chosen documents to the top.

SettingWhat it does
Filter FieldThe metadata field a filter applies to, for example a field that records each document’s product or type.
Static Default Filter Value (when no runtime filter is passed)The filter value NeuralSeek applies when a Seek call does not pass a filter of its own. Runtime filters are covered in Dynamic filters.
Re-Sort FieldThe field whose values the re-sort list matches.

Re-Sort values list. carries its own help text: “Enter a prioritized list of values you want to re-rank above other results, regardless of KB score.” To use it:

  1. In Re-Sort Field, choose the field to match.
  2. Fill in Priority and Value or RegExp in the table’s row.
  3. To add another value, select the button at the end of the row (tooltip Add a new row.).

Documents whose field matches a row rank above the rest, whatever their KB score. Use it to put internal content ahead of a general web crawl, for example, without excluding anything.

Enable Advanced Schema is the last control of every external store’s form.

Limits and interactions

Section titled “Limits and interactions”
  • Changing KnowledgeBase Type replaces the form. The fields of the previous type are no longer shown, so fill in the new type’s connection and mapping before you save.
  • KnowledgeBase Tuning follows the type. With No KnowledgeBase, KnowledgeBase Tuning shows Snippet size in place of Expansion Window. How many documents a Seek takes, how they are scored and the query cache are set there as well.
  • Hybrid & Vector Search Settings exists only for ElasticSearch and watsonx Discovery. It appears as its own section of the dialog once you pick either type.
  • Answer language. KnowledgeBase Language describes the content; the answer language is Default Output Language in Platform Preferences.

FAQ

Section titled “FAQ”

Which KnowledgeBase Types need no connection details?

Section titled “Which KnowledgeBase Types need no connection details?”

NeuralSeek KB and No KnowledgeBase show only KnowledgeBase Type, KnowledgeBase Language and Notes. Virtual KB adds one choice, the mAIstro Virtual KB agent. Every other type asks for its store’s address and credentials.

Where do I choose Lucene, vector or hybrid search?

Section titled “Where do I choose Lucene, vector or hybrid search?”

Only ElasticSearch and watsonx Discovery offer it, in the Hybrid & Vector Search Settings section that appears after KnowledgeBase Tuning once you pick either type. See Hybrid, vector and semantic search.

Does KnowledgeBase Language change the language of the answer?

Section titled “Does KnowledgeBase Language change the language of the answer?”

No. It states the language of your content. The answer language is Default Output Language in Platform Preferences; Language explains how the language settings work together.

Why do my answers show sources without titles or links?

Section titled “Why do my answers show sources without titles or links?”

Check Document Name Field and Link Field in the field mapping. They must name the fields of your index that hold the title and the URL.

How do I make some documents always rank first?

Section titled “How do I make some documents always rank first?”

Choose the field to match in Re-Sort Field, then add a row per value with its Priority and Value or RegExp, using Add a new row. for each extra value. Documents that match a row rank above the others, whatever their KB score.
