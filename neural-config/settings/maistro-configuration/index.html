mAIstro Configuration

mAIstro Configuration lists the external marketplaces that builders on this instance can load agents from in mAIstro. Each marketplace is one row with an endpoint and an API key. The list is optional: leave it empty when you have no external marketplace to register, and add a row when your organization keeps a shared agent library on another NeuralSeek instance.

You do not need an entry here to use NeuralSeek’s own agents and templates.

Where to find it

Section titled “Where to find it”

Go to Neural Config > Default Config > Edit Configuration > mAIstro Configuration. The section is near the end of the dialog, below Intent Matching & Cache Configuration and above Secrets. The dialog and its footer are covered in Save or propose a change.

Settings

Section titled “Settings”

Marketplaces

Section titled “Marketplaces”

The section describes itself as follows:

Configure optional external marketplaces for mAIstro. Each marketplace requires an endpoint and API key. You may configure multiple marketplaces or leave the list empty.

The table has an Endpoint column, an API Key column, and an action column. Each filled row is one marketplace. The empty last row holds the add button.

SettingWhat it doesWhen to change it
Marketplace endpointThe API address of the marketplace, for example https://marketplace.example.com/api. The template library of another NeuralSeek instance can serve as a marketplace.When you register a marketplace, or its operator moves it to a new address.
Marketplace API keyThe API key for that marketplace. It is a credential the marketplace issues, not a NeuralSeek API key. After you save it, the box shows *** in place of the key, so a stored key cannot be read back here.When you register a marketplace, or its operator rotates the key.
Show passwordThe eye button inside the key box. It reveals the key you are typing, so you can check it before you save.When you enter or replace a key and want to confirm it is correct.
Add marketplaceThe button in the empty last row (tooltip: “Add an external marketplace.”). It adds a new Endpoint / API Key row.When you want builders to have access to one more marketplace.
Remove marketplaceThe trash button at the end of a filled row (tooltip: “Remove this marketplace.”). It deletes that row, endpoint and key together.When a marketplace is retired, or builders on this instance should no longer use it.

Every row needs both an endpoint and a key. Ask the owner of the marketplace instance for the exact address and key to use.

Register, rotate or remove a marketplace

Section titled “Register, rotate or remove a marketplace”

To register a marketplace:

  1. Open mAIstro Configuration as described in Where to find it.
  2. In the empty last row of the table, select Add marketplace.
  3. In the new row’s Marketplace endpoint box, enter the marketplace’s API address.
  4. In the new row’s Marketplace API key box, enter the key the marketplace issued to you.
  5. Select Save to apply the change, or Propose Changes to submit it for review. Both are explained in Save or propose a change.

To rotate a key, replace the value in that row’s Marketplace API key box and save. To stop using a marketplace, select Remove marketplace in its row and save.

Where the marketplace’s agents appear

Section titled “Where the marketplace’s agents appear”

Builders browse and load a registered marketplace’s agents on the Agent Marketplace screen in mAIstro.

The marketplace key belongs to the marketplace. NeuralSeek’s own keys are managed on API keys.

FAQ

Section titled “FAQ”

Do I have to configure a marketplace?

Section titled “Do I have to configure a marketplace?”

No. The section says you “may configure multiple marketplaces or leave the list empty.” An empty list means no external marketplace is registered.

Can I register more than one marketplace?

Section titled “Can I register more than one marketplace?”

Yes. Each Add marketplace adds another row, and each row is a separate marketplace with its own endpoint and key. Remove marketplace deletes one row without affecting the others.

Can another NeuralSeek instance serve as a marketplace?

Section titled “Can another NeuralSeek instance serve as a marketplace?”

Yes. Another NeuralSeek instance’s template library can act as a marketplace. Ask the owner of that instance for the endpoint and an API key.

Why is the API key shown as ***?

Section titled “Why is the API key shown as ***?”

A saved key is not sent back to the browser, so the box shows *** in its place and the stored key cannot be read here. Show password reveals only a key you are typing, before you save. To change the key, type the new one over *** and save.
