---
title: "Agent Registry node"
description: "Select one or more agents from an Agent Registry to accomplish a task, and loop through the resulting plan."
---

## Select an Agent

Select a single agent from an agent registry to accomplish a task

:::note[Parameters]

- **registry**: The Registry to select from

- **query**: The query to use to choose the correct agent

- **modelCard**: The LLM to use
:::

---

## Agent Plan

Select an ordered list of agents to accomplish a task

:::note[Parameters]

- **registry**: The Registry to select from

- **query**: The query to use to choose the correct agents

- **modelCard**: The LLM to use
:::

---

## Agent Loop

Loop thru an Agent Plan. Must be used with selectAgentPlan
