## Brave Search 


Search the web using Brave.
:::note[Parameters]

- **query**: The search query

- **apiKey**: Your api key

- **count**: 
    - **text**: The number of responses
    - **min**: 1
    - **max**: 20
    - **step**: 1
    - **default**: 5

- **cache**: Cache results
