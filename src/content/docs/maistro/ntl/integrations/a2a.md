## a2a

Call an agent by a2a.

:::note[Parameters]

- **url**: The URL of the agent

- **text**: The text to send

- **data**: The data to send

- **authHeader**: The authentication header

- **apikey**: The api key

- **taskId**: the task id

- **operation**: The operation
:::
