Deployment & platforms

Section titled “Deployment & platforms”

SaaS

Available on IBM Cloud, Microsoft Azure, and AWS — all with the same feature set. Some plans are specific to a single hyperscaler.

On-premise & air-gapped

Run on any cloud or your own hardware, supporting HIPAA, govCloud, and FedRAMP requirements — it can run completely isolated from a network connection.
